# Portfólio — instruções para o Claude

- Este site segue o meu Design System: leia `design-system/DESIGN.md` (modo Editorial) antes de mudar qualquer coisa visual.
- Cores, fontes, espaçamentos e raios vêm só das variáveis de `design-system/tokens.css`. Nada de hex, px de espaçamento ou fontes soltas.
- Componentes com prefixo `an-` vêm de `design-system/components.css`; estilos próprios do site ficam em `assets/css/site.css`.
- Não edite os arquivos de `design-system/`: são uma cópia do Design System e são substituídos quando ele muda.
- O site é estático (HTML + CSS, sem build), publicado no GitHub Pages. Não adicionar frameworks, bibliotecas de animação ou templates.
- Conteúdo sempre real: nada de números, depoimentos ou projetos inventados.
